# Reproducing the IK1-response readout comparison

This is a descriptive reanalysis of deposited **gene counts**, not raw-read alignment, a DESeq2 result, an independent experiment, or an evaluation of clinical response. The useful output is a shortlist of transcript measurements to consider for independent follow-up, with transparent model, replicate and normalization sensitivity.

## Rebuild

Requires Python 3.10 or later. From the repository root:

```sh
python -m pip install -r analysis/requirements.txt
python analysis/build_data.py --inputs /path/to/public-input-cache --download
```

The command downloads six public inputs if absent, checks every SHA-256 against the pinned values in `build_data.py`, rebuilds `data.js`, and writes `analysis/checks.json`, `provenance.json`, `summary.json`, and `sample-manifest.csv`. Omit `--download` to use an existing cache. `--output /path/to/rebuild` writes to another directory for comparison. Input cache files are not part of the public site. A changed source stops the rebuild; hashes should not be bypassed or automatically updated.

The browser recomputes selected-gene effects and shortlist filters from the exact counts and global normalization factors in `data.js`. The published Python summary provides independent expected values for browser checks.

## Public sources and biological units

- [Paculova et al., 2025 preprint](https://pmc.ncbi.nlm.nih.gov/articles/PMC12776271/), DOI `10.64898/2025.12.29.696402`, version 1. It was explicitly marked not peer reviewed when inspected on 21 October 2026.
- [GSE310958](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE310958): deposited `GSE310958_MXP5_PDX2_raw_counts.tsv.gz`, under superseries GSE310976. Counts were generated by the authors using STAR and hg38/GENCODE v36; they are not aligned anew here.
- Eight libraries: two models (MXP5, PDX2), two conditions (GFP control and IK1), and two biological replicates per condition/model. They represent 24-hour induction. Replicate labels **do not establish matched control/IK1 pairs**.
- PDX2 libraries GSM2410132, GSM2410133, GSM2410140 and GSM2410141 were reused from [GSE90659](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE90659), originally released in 2017, and reprocessed for GSE310958. Model is confounded with historical library preparation/instrument: MXP5 metadata lists Direct-zol/NEBNext/HiSeq1500, while legacy PDX2 metadata lists TRI or column extraction/KAPA/HiSeq2000. Compare within-model effects; do not interpret cross-model baseline differences as purely biological.
- Exact GENCODE v36 gene identifiers, names and types are obtained from the official [UCSC attribute table](https://hgdownload.soe.ucsc.edu/goldenPath/hg38/database/wgEncodeGencodeAttrsV36.txt.gz), with its pinned [SQL schema](https://hgdownload.soe.ucsc.edu/goldenPath/hg38/database/wgEncodeGencodeAttrsV36.sql). This is not a current-version BioMart remapping. Transcript records are collapsed to unique gene ID/name/type tuples. Only unambiguous tuples are used; unmatched identifiers remain literal ENSG IDs. 60,563 of 60,624 count identifiers are annotated, and 61 remain unmapped. The full EBI v36 GTF transfer was not used because it did not complete.

## Transformations

1. Validate the eight expected columns, integer nonnegative counts and Ensembl identifier form. Sum exact duplicate identifiers. There are 60,669 source rows and 60,624 unique IDs; 45 IDs were duplicated. Forty-four duplicate pairs contain only zeros; the remaining pair contains one nonzero count in total. No cause for the duplicate naming is assumed.
2. Retain all 60,624 IDs, including all-zero rows. No gene is removed from the browser dataset.
3. **CPM:** divide each count by its library's total assigned gene counts and multiply by one million. The denominator is not total sequenced reads.
4. **Median ratio:** independently within each model's four libraries, retain genes positive in all four; compute each gene's geometric mean; take each column's median count/geometric-mean ratio; rescale the four factors to geometric mean one. MXP5 uses 19,263 reference genes and PDX2 uses 17,244. This is only a size-factor calculation, not DESeq2 model fitting, dispersion estimation or significance testing. It assumes many genes remain comparable and cannot recover absolute per-cell RNA abundance without external standards.
5. **Mean response:** `log2(mean(normalized IK1)/mean(normalized GFP))` within each model. No pseudocount is used. A zero numerator or denominator yields missing data, not an infinite or manufactured effect.
6. **Replicate sensitivity:** compute all four unpaired IK1-versus-GFP log2 ratios per model. These are four overlapping comparisons derived from **n=2 per condition**, not four independent replicates, a confidence interval, or uncertainty bounds with nominal coverage.
7. **Expression floor:** both condition mean CPM values in both models must exceed or equal the selected floor (four means in total). This eligibility test uses CPM regardless of effect normalization.
8. **Mean-only rule:** both model mean effects meet the selected magnitude and share a direction. **Strict rule:** additionally every one of the four finite sample ratios in each model meets the same magnitude in that shared direction. Thresholds are exploratory choices, not validated assay acceptance criteria. Strict candidates rank by the weakest absolute effect among the eight ratios; ties use the Ensembl ID. Mean-only candidates rank by the smaller absolute model mean effect.

At the initial settings (CPM floor 1, log2 effect floor 0.5, strict support), median-ratio normalization yields 1,189 candidates versus 2,475 under the mean-only rule. CPM gives 1,150 versus 2,443; 1,087 satisfy the strict rule under both normalizations. These are rule-dependent descriptive counts, **not significant genes**.

## Actual GitHub-derived component

The [Schjerven-coauthored 2021 ssvQC paper](https://doi.org/10.1186/s13104-021-05781-8) directly links the collaborative [FrietzeLabUVM/ssvQC repository](https://github.com/FrietzeLabUVM/ssvQC). The repository was fetched and inspected at commit `90a38bf72a97db43cdcdbb4e68bea9a4ceb389c5`.

Its `R/ssvQC_correlation.R` pivots feature counts to a feature-by-sample matrix and computes `cor(mat)`, the default Pearson correlation. `pearson_from_ssvqc` implements that source-defined primitive for the deposited gene-count matrix. This deliberately changes the feature type from genomic peaks to genes. Raw-count correlation is accompanied by `log2(CPM+1)` correlation as a sensitivity view. The `+1` is used **only** for that QC transformation, never for gene-response ratios.

The complete R package, read alignment, BAM processing, FRiP and strand-cross-correlation were **not run**. This is not a claim that ssvQC was validated for RNA-seq. Correlation is a contextual sample-similarity check, not a sample-exclusion rule or proof of data quality. Repository sample BAMs from breast cancer CTCF experiments were not used.

The original source file is downloaded at the exact commit and hash-checked during rebuild. The adapted Pearson calculation is tested against NumPy `corrcoef`, an independent scalar `math.fsum` formulation for every raw-count sample pair, and known linear/reversed fixtures. The size factors are independently checked using scalar geometric means and medians. The machine-readable results are in `checks.json`; all errors must be below `1e-12`.

## Interpretation and follow-up limits

ERG is an already-established result in the source study, not a newly discovered dependency. MYC illustrates why a mean response need not survive every replicate comparison. Surface-marker transcripts do not establish surface protein changes. HPRT1 is responsive in this dataset, so a familiar housekeeping name is not automatically a valid qPCR reference. An apparently flat transcript is not a validated reference either. Test primer specificity/efficiency, reference stability, viability/growth state and IK1 induction with appropriate controls in the actual experiment.

IKZF1 gene-level counts cannot separate endogenous mutant transcripts from the induced IK1 transgene or determine isoform abundance. Functional/cellular readouts and causality require experiments. The proposed follow-up records contain no observed qPCR or protein measurements.

This is an assistant-supported application analysis, not evidence of independent implementation or hands-on library preparation, primary-cell culture, advanced flow cytometry or colony management. Scientific ownership and data credit remain with the original investigators.
